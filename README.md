# git-practice

Git 从零练习仓库：建仓、提交、分支、回退、Patch、编码规范。

## 目录结构

| 路径 | 用途 |
| --- | --- |
| `src/hello.c` | 带中文注释的最小 C 程序，用来观察 UTF-8 与换行 |
| `docs/commit-convention.md` | 提交信息规范模板 |
| `.gitattributes` | 换行 / 二进制策略 |
| `.editorconfig` | 编辑器统一编码与缩进 |
| `.gitignore` | 忽略构建产物 |

## 练习进度

- [ ] 第一次提交

- [ ] 回退（restore / reset / revert）
